# 额度监控（Quota Monitor）

当用户询问当前额度、剩余配额、重置时间，或要求打开额度监控界面时：

1. 直接调用 MCP 工具 `open_quota_monitor`（无需任何参数 `{}`）。
2. 工具会在界面上渲染交互式可视化额度监控面板（支持侧边栏面板、全屏视图和对话内联展示），并在结果中返回当前额度摘要。
3. 在回复中简洁补充关键数字即可，无需重复堆砌冗长表格。
